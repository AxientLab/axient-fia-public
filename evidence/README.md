# Evidence records

The files in this directory are compact, publication-safe evidence metadata.
They contain canonical identities and registries, not raw receipts, traces,
runtime trees, operating-system paths, credentials, or internal operational
artefacts.

- phase17b-summary.json — top-level canonical identifiers.
- all12-manifest.json — twelve parent FIA records and their unique correlations.
- scenario-registry.csv — citable scenario registry.
- evidence-layer-registry.csv — 84 registered derivation positions.
- materialization-manifest.json — two clean materializations and comparison.
- strict-package-manifest.json — deterministic archive identity.
- p01-p17-replay-manifest.json — ordered selected replay outputs.

The registry term is "seven retained evidence layers with registered
derivations". It does not assert a separate independence property for each
layer.
