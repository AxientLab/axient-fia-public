# Publication-card metadata

`PUBLICATION_SITE_METADATA.json` is an unmodified, byte-for-byte copy of the
supplied publication-card metadata. It is used to populate preview/publication
surfaces for Paper IV, Paper V, and the standalone AEMB v0.2 article.

Submission-form metadata containing contact fields is intentionally excluded
from this public repository. The r0.5.1 article records carry no issued arXiv
or SSRN identifiers: both statuses remain `forthcoming` until owner-supplied
metadata is available.
