# Financial Interaction Assertions

The registry contains **12 parent FIA records**. Each parent has one unique
correlation and seven registered evidence-layer positions. FIA-11 is a single
parent assertion with two mandatory semantic subcases; it does not create
FIA-13 or FIA-14.

| Category | Assertions |
| --- | --- |
| Admission | FIA-01, FIA-02, FIA-03 |
| Settlement | FIA-04, FIA-05 |
| Liquidation | FIA-06, FIA-07 |
| Evidence | FIA-08, FIA-10 |
| Capital | FIA-09 |
| Capability | FIA-11 |
| Governance | FIA-12 |

The machine-readable canonical registry is
[../evidence/scenario-registry.csv](../evidence/scenario-registry.csv).
For the settlement edge and capability subcases see
[FIA-04-05-boundary.md](FIA-04-05-boundary.md) and
[FIA-11-subcases.md](FIA-11-subcases.md).
