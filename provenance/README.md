# Provenance

The selected provenance chain is an ordered P01–P17 replay. Its published
result identities are in [P01-P17.md](P01-P17.md) and the machine-readable
manifest in [../evidence/p01-p17-replay-manifest.json](../evidence/p01-p17-replay-manifest.json).

[source-claim-registry.csv](source-claim-registry.csv) maps each public claim
type to a compact publication artefact. It deliberately does not expose
internal workspace locations, raw execution logs, or operational sources.
